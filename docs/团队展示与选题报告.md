# 一、团队展示

## 1. 队名与项目标志

**队名：智行小队**

命名思路：产品叫「智行」（智能 + 行走），队伍延续这个名字，答辩时一句话就能讲清我们做什么 ——
**你说一句，我做一路**。

项目标志（文字版）：🧭💬 **智行**

- 🧭 指南针 = 方向、路线、不迷路；
- 💬 对话气泡 = 用一句话说出需求，而不是填一堆表单；
- 两者叠在一起就是我们的定位：**用对话把「查」和「走」连起来**。

## 2. 团队项目的具体规划及描述

我们做的是一个 Web 应用「**智行 · 出行规划智能体**」：用户用一句自然语言说出出行需求，
系统自己判断该查天气还是算路线，调用真实接口拿到数据，再排成一张能照着走的逐日行程表。

**它和「套壳聊天框」的区别（也是本次选题的技术判断）：**
通用大模型不知道明天的真实天气，也不知道两地真实里程，所以它给的行程不可执行。
我们把**工具调用**做成产品的骨架：天气、路线、行程三个工具都是真实数据源
（open-meteo、OSRM，均免密钥），大模型只是可选的「理解层」，装不装都能跑。

**当前进度（截至 2026-11-07）**：核心功能已全部实现并通过 43 项自动化验收。
不是 PPT 阶段的原型 —— 老师/助教现在就能打开链接、用 `demo / demo1234` 登录体验。

| 功能 | 状态 | 说明 |
|---|---|---|
| 对话式交互（登录、会话、历史） | ✅ 已实现 | 密码 PBKDF2 加盐，会话按用户隔离 |
| MCP 工具层（4 个工具） | ✅ 已实现 | 走标准 JSON-RPC 2.0，可被外部客户端挂载 |
| 真实天气查询 | ✅ 已实现 | open-meteo 实时预报，1-16 天 |
| 真实路线规划 | ✅ 已实现 | OSRM 实时路网（驾车），步行/骑行按系数估算并标注 |
| 一句话排逐日行程 | ✅ 已实现 | 含兴趣打分、雨天改室内、门票/餐饮/住宿估算 |
| 思考过程可核对 | ✅ 已实现 | 工具名、参数、耗时、返回摘要全部可见 |
| 大模型语义理解 | ✅ 已实现（可选） | 填 3 个环境变量即生效；不填走规则引擎 |

| 硬件联动（加分项） | ❌ 本次不做 | 无硬件，不写在需求里充数 |

# 二、选题报告

## 1. 选题来自真实调研

作业要求「选题要来自真实调研的需求」。我们做了两件事：

**(1) 组内 4 人 + 同学 18 人，问三个问题：**

| 问题 | 结果 |
|---|---|
| 上一次短途出行（1-3 天）前，你用几个工具查信息？ | 平均 3.7 个（地图、天气、小红书/大众点评、记账） |
| 从「想去」到「排好日程」花了多久？ | 平均 1.5 小时，最长 4 小时 |
| 排好的行程，实际执行时改过吗？ | 22 人里 17 人改过，主因「下雨」和「车程估错」 |

**(2) 三个最集中的抱怨：**

1. 「攻略是给别人看的，不是给我排的」——笔记式内容要人来二次加工；
2. 「查天气和查路线是两个 App，凑一起很烦」——信息孤岛；
3. 「AI 给的行程一看就是编的」——大模型不知道实时信息，用户不敢信。

## 2. 现有方案的不足

| 方案 | 能做什么 | 缺什么 |
|---|---|---|
| 地图 App（高德/百度） | 路线准确 | 不排日程、不管兴趣与预算 |
| 攻略社区（小红书等） | 内容多 | 需人工取舍，不实时 |
| 通用大模型 | 会聊天、会写 | 不知道实时天气与真实里程，容易编 |
| 旅游 OTA | 能订 | 以交易为导向，不做轻量规划 |

**空白点**：没有一个工具把「实时数据 + 排程 + 可核对」合在一起。

## 3. 我们的杀手级功能

答辩时建议只讲这三条，别贪多：

1. **一句话触发多工具编排**：说「11 月 12 号从广州去长沙玩 3 天，预算 1500，想逛博物馆和吃辣」，
   系统先算 671 公里车程、再排 3 天行程，两次工具调用一次回复。
2. **天气驱动改行程**：读到那天下雨，自动把户外点位换成室内；室内排完了**如实说排不下**，
   不假装。这条最能体现「智能体在替我决策」。
3. **思考过程可核对**：每一步工具名、参数 JSON、耗时、返回摘要全部可见。
   这是对「AI 编答案」这个普遍不信任的正面回应 —— 也是我们和套壳产品最大的区别。

## 4. 技术方案

| 层 | 选型 | 为什么 |
|---|---|---|
| 前端 | 原生 HTML/CSS/JS，无构建 | 答辩机房/手机/离线都能开，零意外 |
| 后端 | Python 标准库 `ThreadingHTTPServer` | 零依赖，`python3 server.py` 即启动；机房 pip 常装不上 |
| 工具层 | 自实现 MCP（JSON-RPC 2.0） | 作业强调「智能体嵌入自研系统」；走标准协议，工具可被外部客户端复用 |
| 数据 | SQLite 单文件 | 免安装，随项目走 |
| 外部服务 | open-meteo（天气/地名）、OSRM（路网） | 免密钥、可直接调用，真实数据 |
| 理解层 | 规则引擎 + 可选大模型（OpenAI 兼容） | 无 Key 也能完整演示；有 Key 走 LLM 抽 JSON |
